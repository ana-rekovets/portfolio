Causal Inference · Experimentation · LMU Munich · Mar 2026

When Is TSLS Actually LATE?

Proved that linear instrumental-variables estimation with covariates is only causally valid under a "rich covariates" condition (Blandhol et al., 2022), deriving the paper's core propositions before testing the result on Project STAR (N=11,599 students) with Ramsey RESET diagnostics — a question directly relevant to how experimentation results get validated in industry A/B testing pipelines. Standard TSLS failed the specification test in every grade cohort, with specification bias inflating the estimate by up to 32.6% by Grade 3, while DDML alternatives yielded systematically lower, more robust estimates.

Analyzed the full FY2024 NYC citywide payroll (217,402 full-time, full-year employees) to measure the gender pay gap and decompose it into within-job and job-allocation components using a Blinder-Oaxaca framework — the same people-analytics methodology used to audit compensation equity and flag allocation-driven disparities before they surface in attrition or engagement metrics. Covers the complete pipeline from EER diagram to 3NF schema to 15 analytical queries spanning joins, correlated subqueries, and relational division.

-- Q14: Relational division
-- stores accepting ALL payment methods

SELECT pos.point_id,
       pos.name, pos.city
FROM POINT_OF_SALE pos
WHERE NOT EXISTS (
  SELECT 1
  FROM (
    SELECT DISTINCT payment_method
    FROM PAYMENT_METHOD
  ) allm
  WHERE NOT EXISTS (
    SELECT 1
    FROM PAYMENT_METHOD pm
    WHERE pm.point_id = pos.point_id
      AND pm.payment_method
        = allm.payment_method
  )
)
ORDER BY pos.point_id;
